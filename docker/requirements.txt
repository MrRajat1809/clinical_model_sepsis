# Pinned environment for the Sepsis-3 portability pipeline.
#
# Every version below was read from a container that completed a full pipeline
# run, not chosen. That distinction matters: an unpinned data-layer package is a
# silent source of moving results. Rebuilding this image on a second machine
# resolved a different DuckDB, and the MIMIC cohort moved with it. Nothing here
# may be relaxed to >= without accepting that the numbers can change between
# builds.
#
# To re-lock against a future environment, run this inside a container that has
# completed a run and replace the pins below with its output. numpy and tqdm
# come from the base image's conda environment and are recorded as
# `name @ file://...` rather than `name==version`, so read those two with
# `pip show numpy tqdm`:
#
#     pip freeze
#
# torch, torchvision and torchaudio are the versions already present in the
# base image (pytorch/pytorch:2.2.1-cuda12.1-cudnn8-runtime). They are pinned so
# pip treats them as satisfied instead of upgrading them out from under CUDA.
